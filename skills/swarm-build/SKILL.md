# swarm-build：网页的蜂群搭建加载效果

## 什么时候用

用户想给自己做的网页加一个开场或加载效果，看起来像一群 AI Agent 一起把页面搭出来。例如：

- 「给我的网页加上 swarm-build 加载效果」
- 「让一群光标把我的页面搭出来」
- 「加一个炫酷的加载效果」

## 效果

- 打开网页：约 20 个彩色光标在屏幕中间围成一圈。
- 首屏和往下滚到的每一段先是空白（和这段底色一样，带格子）。光标从屏幕边飞进来，给主要区块拉框、标尺寸，再沿框把空白剪开，露出真内容。
- 一段搭完，光标就淡出；滚到下一片空白再来一批。全部搭完，右下角出一句「这个页面由 N 个 AI Agent 一起搭成」。
- 不改网页本身的任何元素：只盖一层，页面自己的动画、3D、脚本生成的内容都照常；固定在顶部的导航不盖。
- 系统开了「减少动态效果」就不播；网址加 `?noswarm` 临时关掉；任何一段卡住超过 12 秒自动露出来。

## 步骤

1. **找到网页入口**。先问清楚或自己判断是哪个页面：
   - 纯 HTML：要加效果的那个 `.html` 文件（通常是 `index.html`）。
   - Vite（React、Vue、Svelte 等）：项目根目录的 `index.html`；静态文件放 `public/`。
   - Next.js：静态文件放 `public/`，在根布局（`app/layout.tsx` 或 `pages/_document.tsx`）的 body 最后加脚本。
   - 其他框架：找到最终输出 `</body>` 的模板，和能原样发布静态文件的目录。
2. **复制脚本**。把本技能里的 `assets/swarm.js` 原样复制到网页能访问到的位置：纯 HTML 放在和页面同一个文件夹；有 `public/` 的项目放进 `public/`。不要引用外链 CDN（国内网络常打不开），也不要改脚本内容。
3. **加一行**。在页面 `</body>` 前加：

   ```html
   <script src="swarm.js"></script>
   ```

   路径按第 2 步放的位置写：放在 `public/` 里通常写 `/swarm.js`。Next.js 用 `<Script src="/swarm.js" strategy="afterInteractive" />`。
4. **可选参数**（用户提了再加，写在同一个 script 标签上）：
   - `data-agents="24"`：同时最多几个光标，6–60，默认 24。
   - `data-text="这个页面由 {n} 个 AI Agent 一起搭成"`：结束时那句话，`{n}` 会换成一共派出的光标数。
5. **验证**。起一个本地服务打开页面（直接双击 html 也行）：
   - 开场有一圈光标；首屏被搭出来；往下滚，空白段被搭出来；搭完光标消失。
   - 浏览器控制台没有报错。
   - 网址加 `?noswarm` 时页面直接显示。
   - 看不到效果时，先查系统是不是开了「减少动态效果」，再查脚本路径是不是 404。
6. **发布**。项目要发到网上（GitHub Pages、Vercel 等）的话，把 `swarm.js` 和改过的页面一起提交、推送。

## 规矩

- 只加一个文件、一行代码；不改页面其他内容和样式。
- 不改 `swarm.js`。用户想调效果，先用第 4 步的参数。
- 想去掉效果：删掉那一行 `<script>`，再删掉 `swarm.js`。
