# swarm-build

让一群 AI 光标，把你的网页搭出来。

打开网页时，一群彩色光标先在屏幕中间围成一圈；往下滚，下面先是空白，光标从屏幕边飞进来，拉框、标尺寸，把内容一块块搭出来，搭完就淡出离开。效果看 `demo/index.html`（下载后用浏览器打开）。

这是一个**技能**（SKILL.md），哪个 AI 工具都能用：装进支持技能的工具，或者直接把这个仓库链接发给你的 AI。

## 怎么装

先把仓库拉下来：

```bash
git clone https://github.com/xiaopu-ai/swarm-build
```

然后二选一：

- **你的 AI 工具支持技能（SKILL.md）**：把 `skills/swarm-build` 这个文件夹放进它的技能目录。各家目录不一样，看它的说明。
- **不支持也没关系**：把这个仓库的链接发给你的 AI，让它照 `skills/swarm-build/SKILL.md` 做。

## 怎么用

对你的 AI 说一句：

```
给我的网页加上 swarm-build 加载效果
```

它会把 `swarm.js` 放进你的项目，在页面最后加这一行：

```html
<script src="swarm.js"></script>
```

不用 AI，自己加也行：把 `skills/swarm-build/assets/swarm.js` 复制到网页旁边，再加上面这一行。

## 可以调的

写在同一个 `<script>` 标签上：

| 参数 | 作用 | 默认 |
|---|---|---|
| `data-agents` | 同时最多几个光标（6–60） | 24 |
| `data-text` | 结束时右下角那句话，`{n}` 换成一共派出的光标数 | 这个页面由 {n} 个 AI Agent 一起搭成 |

网址后面加 `?noswarm` 可以临时关掉效果，改网页的时候方便。

## 原理

- 把页面按上下切成几段，每段盖一层和它底色一样的空白（带格子）。
- 某一段滚进屏幕，光标飞过去，挑出这段的主要区块，拉框、标尺寸，再沿框把空白剪开。
- 不改网页本身的任何元素，所以页面自己的动画、3D、脚本后来生成的内容都照常；固定在顶部的导航不盖。
- 系统开了「减少动态效果」就不播；任何一段卡住超过 12 秒自动露出来。不依赖任何库，一个文件约 400 行。

灵感来自 [Swarm](https://califa.github.io/swarm-site/) 网站的滚动搭建效果；本仓库的代码是重新写的。
